# Windows 本地指纹浏览器 V1 开发规格

状态：待开发。当前可交付物是前端交互原型，真实浏览器服务仍需实现。本规格整理已确认需求，作为 GitHub 开发票据的共同目标。

## Problem Statement

使用者需要在一台 Windows 电脑上长期管理多个电商浏览器环境。普通多窗口不能提供独立浏览数据、稳定设备档案、明确代理出口和可恢复的配置。已有前端能演示操作，但启动、代理检测与快照均不代表真实内核能力，尚不能用于日常店铺操作。

## Solution

把现有六页工作台接入本机 Go/Wails 应用服务与 SQLite，使用已指定的 fingerprint-chromium 内核。用户创建一次环境，保存固定档案、内核和网络策略，之后能够真实启动、停止、重开、备份和恢复。软件无需云账号或团队系统，不设保存数量或保持运行数量的产品配额；实际资源不足时给出准确结果和恢复入口。

## User Stories

1. 作为本机使用者，我希望无需登录即可打开工作台，以便独立管理自己的环境。
2. 作为使用者，我希望创建任意数量的环境，以便按业务需要扩充，数量由实际电脑资源决定。
3. 作为使用者，我希望按名称、编号、分组和状态找到环境，以便快速回到指定工作。
4. 作为使用者，我希望创建后重开软件仍能看到配置，以便长期使用。
5. 作为使用者，我希望每个环境有独立浏览数据，以便不同环境不会读到彼此的 Cookie、LocalStorage 或 IndexedDB。
6. 作为使用者，我希望一次生成固定设备档案，以便每次重开保持原身份输入。
7. 作为使用者，我希望先预览新档案再保存，以便取消编辑时不改变旧档案。
8. 作为使用者，我希望明确重新生成时保留浏览数据，以便自主选择身份变化。
9. 作为使用者，我希望同内核的旧档案修订可恢复，以便撤回不合适的修改。
10. 作为使用者，我希望知道哪些指纹可编辑、哪些由内核生成、哪些未验证，以便配置真实支持的能力。
11. 作为使用者，我希望每个环境保存精确内核版本，以便默认选项变化不影响旧环境。
12. 作为使用者，我希望缺失或损坏内核时阻止启动并说明原因，以便修复原版本。
13. 作为使用者，我希望从官方来源安装或导入经过校验的内核，以便明确软件实际使用的构建。
14. 作为使用者，我希望一个环境只启动一份有效会话，以便避免重复写入数据目录。
15. 作为使用者，我希望停止只作用于选定环境，以便不影响其他浏览器或工作。
16. 作为使用者，我希望应用或内核异常退出后能核对真实状态，以便继续操作而不误删锁或误判运行。
17. 作为使用者，我希望批量导入代理并预览错误行，以便修正配置后再保存。
18. 作为使用者，我希望每个环境明确选择 HTTP、HTTPS、SOCKS5 或本机直连，以便控制实际网络出口。
19. 作为使用者，我希望带认证的代理可用且密码受本机保护，以便无需把凭据暴露在页面或命令行中。
20. 作为使用者，我希望代理检测显示连接、认证和出口结果，以便判断故障发生在哪一步。
21. 作为使用者，我希望已绑定代理失败时阻止启动和非预期网络出口，以便不被静默切到直连。
22. 作为使用者，我希望代理重连后继续使用原档案，以便网络恢复不改变环境身份。
23. 作为使用者，我希望地区建议经过预览保存才生效，以便代理变化不会自动改写语言和时区。
24. 作为使用者，我希望把 JSON 或 Netscape Cookie 导入指定环境，以便恢复有明确语义的网站会话数据。
25. 作为使用者，我希望导入前看到域名、冲突和过期条目，以便控制合并结果。
26. 作为使用者，我希望空值、会话期限和分区字段被正确处理，以便软件不擅自改写登录数据。
27. 作为使用者，我希望写入后逐项核对实际结果，以便部分失败时知道需要重试什么。
28. 作为使用者，我希望复制配置得到新身份和空数据目录，以便新环境不会继承已有登录状态。
29. 作为使用者，我希望批量创建、代理分配和启动有进度与逐项结果，以便少量失败不掩盖成功项目。
30. 作为使用者，我希望取消剩余任务并保留已完成结果，以便及时收回大批次操作。
31. 作为使用者，我希望保存全量或选定环境的完整本机备份，以便同时保留档案和实际浏览数据。
32. 作为使用者，我希望恢复前检查备份内容、内核要求和覆盖范围，以便避免意外替换。
33. 作为使用者，我希望恢复保持原 seed 和版本绑定，以便继续使用原环境身份。
34. 作为使用者，我希望恢复中断或磁盘不足后仍能回到完整状态，以便原数据可找回。
35. 作为使用者，我希望移除环境先进入本地回收区，以便误操作后能够找回。
36. 作为使用者，我希望内核升级只影响明确选择的环境，并保留升级前备份，以便兼容性异常时恢复。
37. 作为使用者，我希望操作记录说明目标、结果和下一步且不含凭据，以便排查问题。
38. 作为使用者，我希望 Windows 安装、升级和卸载遵守明确的数据保留规则，以便软件维护不会丢失环境。
39. 作为使用者，我希望键盘、窄窗口、空状态和失败提示均可用，以便日常操作清楚可达。
40. 作为开发者，我希望需求、页面、票据和验证证据相互关联，以便每个完成声明都可核查。

## Implementation Decisions

- 以 Environment、FingerprintProfile/Revision、Proxy、Kernel、RuntimeSession、Operation、BackupRecord、Activity 作为统一术语。环境是独立持久身份与数据单元，不等同于一个窗口或 PID。
- 首先提取前端应用服务契约与 DemoAdapter，保留原型行为。当前独立适配器尚不存在；随后用 WailsAdapter 连接本地服务，演示记录与真实记录明确隔离。
- 统一成功、错误、操作 ID 和单调事件序号；修改请求使用 requestId 去重，已有记录采用 expectedRevision。提交事务后才报告持久化成功，任务受理不等于执行完成。
- Windows 桌面是唯一首版平台。真实配置保存到 SQLite，本地应用服务负责文件、凭据、进程和内核；页面不接受任意可执行文件路径或启动参数。
- fingerprint-chromium 是已选内核。每个构建保存精确版本、来源、程序和包哈希及能力记录。README 标称版本、原型 available 状态与真实安装验证分别处理。
- Windows 档案使用有版本的模板；显式保存 seed、语言、时区、CPU 偏好、实际内核身份和生成器版本。管理端控制生成输入，GPU、内存、字体及绘图算法沿用固定内核实现。
- 生成只改变预览，提交才保存修订。查询、启动、停止、改名称和改代理不隐式生成 seed。克隆建立新身份与空目录；恢复保留原身份。
- 受控安装目录和独立用户数据目录由后端解析。环境与规范化目录持有独占锁；监督器核对 PID、进程创建时间与会话身份，保留 Chromium 沙箱。
- 每环境独立代理桥接负责认证；凭据经 Windows 受保护存储读取，浏览器只连接本机桥接端点。明确直连与代理模式分别保存。代理故障不改变策略，不允许隐式 DIRECT 回退。
- Cookie 解析预览和实际写入分开；通过指定环境的受控 CDP 通道写入并核对。空 value、session、过期和 partitionKey 按协议能力保留或明确报告。
- 完整备份包含配置一致性快照、实际浏览数据、档案、版本清单及文件摘要。原型 JSON 不能作为桌面包导入。跨 Windows 用户恢复凭据不作首版承诺，导入须说明凭据可用范围。
- 恢复采用预校验、同卷暂存、维护锁、持久操作日志与回滚。数据库和目录不共享事务，崩溃重开后先恢复一致状态再允许启动环境。
- 升级是新内核安装、测试、选定环境迁移和旧完整数据恢复，不用旧二进制直接打开升级后的目录。
- 每张开发票据交付一个可演示的完整行为；票据只依赖真正阻塞它的前置项。开发顺序由 GitHub 原生依赖决定，不以列表顺序代替依赖判断。

## Testing Decisions

- 主要测试边界是本地应用服务的公开契约：输入一个业务请求，观察返回结果、事件、持久状态及可见副作用。跨界资源使用受控时钟、临时存储和进程/网络夹具；不为私有方法和调用顺序写镜像测试。
- 复用现有 seed、代理文本、Cookie 语义及快照失败保护领域用例，作为关键算法的快速回归；同语义迁移到 Go 后保持同一组行为样本。
- 为环境、指纹、内核、代理、Cookie、长任务和恢复服务验证成功、明确失败、取消、并发冲突与重开行为。实际状态必须来自服务查询和受控资源观测。
- 原型前端仍需浏览器交互回归。已有人工页面检查与截图是参考，不等同于已经提交了 UI 自动化套件；第一张票据补可重复的关键路径检查。
- 真实 Windows 验收覆盖两个环境重开与浏览数据隔离、固定构建参数读取、代理认证和断线出口、Cookie 写后核对、恢复中断回滚、安装升级卸载。前端 CI 不能替代这些证据。
- 各票据附实际执行命令、结果、必要脱敏截图或日志。仅使用合成测试数据；不把真实店铺或平台隐蔽性评分作为开发成功判据。

## Out of Scope

云账号、团队权限、数据云同步、收费配额、第三方浏览器迁移、移动端模拟、特定平台适配模块、插件专项、RPA 和自动注册。指纹隐蔽性评分、不封号承诺，以及任意硬件字段伪装不属于验收目标。首版完整备份优先保证同一 Windows 用户上下文恢复；跨机器凭据可移植性另行设计。

## Further Notes

当前原型的 23 项领域测试与页面演示是起点，不是上述桌面能力已经实现的证明。版本可获取性和参数生效必须在接入时重新验证。没有承诺工期或某台机器的最大真实浏览器并发量。
