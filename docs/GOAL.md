# Windows 本地指纹浏览器持续执行 Goal

授权日期：2026-09-30。范围为本仓库及 [GitHub 项目](https://github.com/axgiroud312-byte/prism-local-browser)。本文件保存已确认执行规则；唯一当前执行位置为 [PROGRESS.md](PROGRESS.md)。

## 固定目标

把当前 React/TypeScript 前端交互原型完成为符合已确认 [PRD](PRD.md) 的 Windows 本地指纹浏览器。采用 fingerprint-chromium、Go/Wails、SQLite，沿用现有六页体验，交付独立浏览数据、固定设备档案、独立代理、精确内核和完整恢复能力。

不设保存数量或保持运行数量的产品配额；调度并发仅用于资源保护，资源不足准确报告。云端、团队权限、同步、第三方迁移和平台专项适配属后续项目。隐蔽性评分和不封号承诺不作为验收条件。

任务为执行授权：正常调查、实现、排错、测试、真实桌面验证、文档、提交、推送和 GitHub 同步持续推进。完成一票自动进入下一票，不逐票询问是否继续；仅遇到确需用户提供资源、权限或操作的外部阻塞才停下。用户明确停止或改变目标时遵循新指示。持久记录使中断后可恢复，不宣称会话之外存在无人运行的后台执行器。

## 每票执行循环

1. 读完整 Issue，检查前置成果实际可用，建立本票验收清单。
2. 实现当前票所需完整用户流程；保留原型独立运行。
3. 按“开发功能 → 相关验证 → 一票收尾完整回归和 CI”推进。开发中只测相关模块与失败项，已建立工具和验证环境直接复用，不因零碎改动反复全量检查或新建测试环境。一票收尾运行 `npm run check`；之后仅文档变化运行 `npm run check:docs`。新增 Go/Wails 能力补可执行检查入口，不省略关键真实操作，不用模拟替代。
4. 真实操作逐项验收，记录版本、合成输入、预期、实际结果和脱敏证据。页面成功、代码完成、构建成功、真实能力生效分别记录。
5. 自查或只读评审，修复影响本票交付的问题。不能删测试、放宽验收、跳过失败路径或用模拟替代真实能力。
6. 更新进度、追踪、验证与交付记录，提交推送本票已检查改动并同步 GitHub；不强推，不夹带用户改动。
7. 全部验收满足、代码已推送、相关自动检查通过、证据可追溯才关闭本票。总规格 #1 保留。自动进入下一票。

远程暂时不可用时保留本地成果，记录待同步项并重试；同步失败不等于功能失败，也不能伪称发布。检查通过后仅因新改动、失败或未解决疑点扩大验证。

## 防止范围漂移与核心不变条件

每个改动关联当前票验收或必要阻塞；无关优化列后续建议。常规可逆细节自主选择。产品范围、技术路线、兼容和验收变化先记录证据影响，仅不可消除的关键歧义询问用户。

- 普通编辑、启动、停止、代理变化不重生成 seed；生成只改预览，保存才提交。
- 克隆为新 ID、新身份和空浏览数据；恢复保留原身份和精确版本。
- 绑定代理失败不静默直连；启动检查与运行期断线保护分别验证。
- 内核缺失或损坏准确失败，不悄悄切换版本；能力来自对应构建证据，不支持字段明确限制。
- 备份包含真实浏览数据，验证执行失败及硬中断后的可恢复一致状态。
- 页面交互沿用已确认方案，必要调整关联需求和验证；demo/native 数据隔离。
- 公开代码与证据仅合成或脱敏；未授权商业材料不复制，分发保留第三方许可。
