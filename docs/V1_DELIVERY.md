# 首版六阶段执行与验收

2026-10-05，沿用 `goal/v1-remaining-integration`。用户已明确确认下述首版范围；当前执行位置见 [PROGRESS](PROGRESS.md)。实现、验证、交付分别记录，正式验收仍为 4/21，另有 14 项已实现待验收。

## 支持条件与范围决策

首版要求 Windows 网络隔离机制正常工作。在此前提下，上游代理掉线、代理桥崩溃、管理程序崩溃均不得使浏览器直连；旧桥端口被普通程序接管也不能绕过保护。BFE/MpsSvc/Dnscache 等底层网络服务自身损坏期间的保护移至后续加固，**不是已经实现或验证的保证**。这是经本轮单独确认的范围调整，不将此前被拒绝的停服实验改记为通过。

Windows Home、fingerprint-chromium、原生 Chromium 沙箱、固定 seed 和独立原数据引用保持要求。当前局部实验仅覆盖 Windows build26200 与精确 148 构建，其他组合没有据此获得支持资格。正常服务状态读值不是隔离生效证明；生产启动必须核对实际会话资源、token/Job、专属桥及就绪结果，缺失、失败、状态未知均拒绝。

无法安全支持的路径由后端禁用，并在界面/指南列出兼容限制。当前 SOCKS5 UDP ASSOCIATE/BIND 和明文 HTTP Upgrade 未支持；安全 WebSocket、DNS、IPv6、WebRTC、UDP/QUIC 的实际策略及出口仍需逐项核实，不能只凭启动参数下结论。

## 阶段与出口条件

| 阶段 | 工作 | 完成标准 |
| --- | --- | --- |
| 1 范围与依赖 | 同步首版支持条件、T11 清单、资源与过时进度 | 本地需求、目标、验收一致；远程未同步及所有未验证项明确 |
| 2 单个代理环境 | 持久资源日志 → 隔离/权限 → 专属桥 → 全树检查 → 真实会话门禁 | 产品启动真实浏览器经指定代理访问；关闭重开后原身份和浏览数据保留 |
| 3 故障与恢复 | 上游、桥、管理程序故障；残留恢复和清理失败 | 无未经代理出口；原环境可恢复；A 不影响 B |
| 4 功能集成 | T14 队列、T20 代理迁移、Cookie 等所有启动入口 | 共用保护链；去重/取消/重试/失败状态正确 |
| 5 集中验收 | 必要全量检查与 14 项已有实现逐票真实验证 | 每票有实际结果；失败有原因，修复后只重测相关路径 |
| 6 安装交付 | 候选包、安装/升级/卸载/重开、人工操作及资料 | 安装包、SHA-256、说明、报告、已知限制及签名状态齐全 |

阶段 2 是当前主要开发目标。资源必须先记录再创建：容器身份、准确会话/Job、目录对象及权限增量均可在中断后找回；未知结果不能释放环境。权限仅授给对应 SID/对象，撤销增量而不覆盖其他权限。新 SID 不改变浏览器 seed 或原数据引用。桥入口以容器身份隔离，桥只连接保存的上游代理；浏览器主进程与子进程都核对，保留 Chromium 沙箱。前检成功或 CreateProcess 成功均不直接发布“运行中”。

## 阶段 3 四组真实验证

| 验证组 | 必需证据 |
| --- | --- |
| 正常外网 | HTTP、HTTPS、允许的 WebSocket 经指定代理，独立受控观察端确认出口 |
| 旁路 | 目标 DNS、IPv6、WebRTC、UDP/QUIC 被代理或阻断；正常对照确实到达，避免把坏测试当成功 |
| 三种故障 | 断上游、结束桥、结束管理程序后无直连；普通程序接管原桥端口仍不可达 |
| 重开与恢复 | ACL 已加但启动中断后可处理残留；数据保留；未确认清理仍占用；A/B 互不影响 |

实验代码的旧证据仅作为实现依据。必须保留每次观测的代码版本、系统/内核构建、输入、对照、实际出口与清理结果。故障后的状态展示不代替网络证据。

## 资源准备与当前缺口

| 资源 | 最晚需要 | 当前事实 / 后续动作 |
| --- | --- | --- |
| 可控代理、独立远端观察端 | 阶段 3；阶段 2 外网闭环也需有效代理 | 仅旧 loopback 合成实验已知可用；外部资源未核实，需可控断线/认证与出口日志，凭据不入仓库 |
| 两个不同版本已核验真实内核 | 阶段 5 迁移回退 | 已有 148 证据不等于两个版本；第二构建待核实，不重复下载已有构建 |
| 干净 Windows 或合适 runner | 阶段 6 | 当前仅已知本机 Home；旧 T03 runner 证据不等于本版运行器可用 |
| 少量人工界面操作 | 阶段 2 产品闭环、阶段 6 最终验收 | 遵守不自动点击；准备可运行产物后提供最短人工操作及观测入口 |
| GitHub 认证、推送/CI 条件 | 远程收尾 | 本轮 `gh issue view 12` 返回 401；公开 REST 可读，未推送/触发 CI；用户需恢复认证 |

缺外部条件只阻塞对应验收，继续不依赖它的实现。不重复已失败的系统服务实验，不在当前工作机注入底层服务故障。

## 执行与记录

主代理唯一写入，子代理只读调查/评审，同时只推进一个主要阶段。每个可验证成果更新进度并本地提交。开发期执行必要类型检查、局部编译、关键行为验证；完整回归集中阶段 5，不运行自动点击。安装包集中阶段 6，之后只因修复/版本变化重建。远程认证恢复后同步 T11 范围、实际检查和未验证项；未满足验收不关闭票，不将本地提交称为已交付。
