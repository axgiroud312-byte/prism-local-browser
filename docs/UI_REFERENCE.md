# 本轮唯一视觉参考与页面清单

更新：2026-10-06。适用于 [#32](https://github.com/axgiroud312-byte/prism-local-browser/issues/32) 总规范及 #33–#37。**用户提供的「完整代码」归档是本轮唯一 1:1 视觉基准**，不再以 Ant-Browser 或之前六页原型决定外观。业务规则仍来自棱镜已有应用服务。

## 1 来源、证据与限制

- 冻结发布标识 **202609160208**，历史记录日期 2026-09-16。本机只读定位、实际来源哈希和研究回放说明保存在仓库外的参考说明中；公开仓库不记录私人绝对路径。
- 研究者在首次导航前拦截所有请求，使用只读归档渲染器及合成业务值，得到 **40 个状态 × 2 视口 = 80 张原参考 PNG**。本票只查看保存的 PNG/测量，不再执行商业前端。
- 所有参考图为 1440×900 或 1280×800 **内容视口**、DPR 1、100% 缩放、zh-CN / Asia-Shanghai、viewport-only。原参考不进入公开仓库；[实现截图](verification/issue33.md#合成证据)仅包含棱镜代码和独立表达的合成数据。
- 647 个历史成功资源中，实际使用的 136 个匹配历史哈希（其中 12 个来自同版本缓存）；另 511 个只冻结当前实际字节，未证明历史语义等价。**不能声称整份归档逐字节等同历史发布或所有原状态完整可还原。**
- 原账号完整菜单配置不可得，导航条目为研究合成值；可核实的是侧栏、顶部、控件几何，不是完整原菜单顺序。设置页有原客户端限制覆盖层；批次结果只注入显示值，运行中与指纹随机通知也不证明真实执行。
- 不复制原 JS/CSS、接口结构、图标、字体、品牌图片或用户数据；实现使用 React、现有 Lucide 图标和自行编写的样式。原破损图标不作为正常设计复刻。

## 5 必须逐项记录的差异

1. **产品裁剪**：无本机服务的云账号/员工组织/权限/套餐配额/购买代理/客服营销/RPA/云手机云电脑/云分享转移不保留入口。不存在独立分组创建、排序、归属、删除服务；不补假实体。
2. **身份与能力**：内核列表来自现有服务，不硬编码归档版本。普通编辑/分组/启停不换 seed；显式换一套只改草稿；克隆新身份、恢复原身份。任意 UA/WebGL/OS 编辑、启动随机身份等无能力字段裁剪。
3. **安全差异**：原 dirty drawer 直接丢草稿、Escape 后焦点不合理；棱镜继续保留未保存确认及可用焦点返回。凭据不回显、代理故障不直连、未知提交核实原任务、已创建后打开失败只重试原 ID。
4. **布局适配**：主色/框架/表行尺寸按冻结图；本机字段替换商业字段后，菜单项数/表单高度可变化，但须有对应说明，不用“大体像”掩盖另一个布局。原 44px 首页槽位只保留空白，不增加无服务首页按钮。
5. **未核实**：511 资源历史等价、完整账号菜单、完整原指南、导出模态、真实保存/启动/检测/下载/取消/实时任务动画仍缺直接原证据。保留为缺口，不发明参考图。

所有新 UI 证据只验证 Vite/合成 bridge，不覆盖旧候选 exe，不改变正式历史 **4/21、T05–T21 / #6–#22 OPEN**。
