## 源码实现

- [`解析`](../../internal/cookies/parse.go)：UTF-8/2MiB、JSON对象数组字段唯一和白名单、Netscape7列/#HttpOnly_/子域名旗标。JSON0为epoch过期，Netscape0/-1为session，JSON-1/省略expires为session；expires/expirationDate/session矛盾拒绝。空字符串value不丢，域名点保留host-only区别，sameSite缺省不当None；安全前缀/None/分区要求Secure，不自动修安全属性。过期只预览/跳过，不发送删除旧同键的过期写。
- 写前作用域/键保护：多个域前导点不得反转hostOnly；含private PSL的域Cookie/单标签域作用域、非规范numeric URL host拒绝。path只支持可原样保存的ASCII规范子集（无点段/百分号/空白/URL分隔/非ASCII），不写后才发现另键已被覆盖。IPv6Cookie域暂明确不支持，负fraction expiry及secure/sourceScheme冲突预览拒绝。
- [`预览/受理`](../../internal/workspace/cookie_import.go)：绑定environment/revision，运行时还绑定session；未知现存冲突不填0。新输入/Discard/关闭/15分钟自动清理，不持久化秘密；所选输入同键只接受一条。提交只接受元数据，requestId持久去重、修订/准确会话/停止与故障保护重核，未明确启动不能自动写。
- [`私有内核能力`](../../internal/kernel/cookies_windows.go)：根pipe Storage.get/set/clearCookies，省略browserContextId使用准确自有浏览器default context，非应用sessionId冒充CDPcontext。每读取/写入/读回组合持同commandGate，callLocked不二次抢锁；值仅内部内存，写不加URL（避免HTTPS隐式Secure）。完整读回按name/domain点/path/分区/值/属性/session/-1/秒时刻核对，缺字段/响应太大不截断计成功。
- [`导入worker`](../../internal/workspace/cookie_worker.go)：每任务2分钟/命令10秒，逐项检查原slot/session/修订；已匹配项不重写，写后未知保留，不补偿其他条目。全量清空明确选择且核对空集合，一次preview仅受理一次，后续只合并失败项；正常/强制停止与退出保护对应任务，迟到结果不能转移到新会话。
- [`持久观测`](../../internal/workspace/cookie_persistence.go)：schema5无新表，accepted/安全结果使用operations，最终操作与安全活动同事务；落盘失败保cookieTasks/profileUse，只重试持久化，不再发CDP。copy-on-write历史，重开未终任务APPLICATION_INTERRUPTED/unknown，无保存的Cookie值、无自动清空/写入。
- [`native对话框`](../../src/components/NativeCookieImport.tsx)：目标环境/ID、隐藏输入/文件、完整预览/选择、合并默认、全量清空额外确认、逐项核对/未知与只重试失败。需要启动时明确cookie-import用途，抑制本次旧标签/网址但不改保存配置/identity；直连确认与proxy门禁保留。关闭输入/预览清理，已发送任务继续可重开看安全报告，旧网页demo不变。

priority/sourceScheme/sourcePort按固定CDP可选字段接入；size/storeId/opaque或不完整分区等不支持输入明确错误。读回partitionKeyOpaque即使false也保留presence，不能冒充未分区Cookie。读回整集合受现有2MiB私有pipe帧限，过大报告不可核对不截断。页面并发写、自然过期及内核容量淘汰可能改变Cookie，不能承诺一次导入锁住浏览器自身；合并代码不主动改无关键，显式全量清空除外。
