# 棱镜浏览器使用指南

适用范围：当前本地集成分支的 Windows 桌面源码。**尚未交付 T21 完整验收安装包。** 已验收计数仍为 4/21；后续功能已编写与真实验证通过是两回事。[当前进度](PROGRESS.md)记录准确状态。旧 0.3.0 预览包的能力见[安装说明](INSTALLATION.md)，不能拿旧包验证新功能。

## 先看这三点

1. **正式代理启动已接入，本机受控闭环已验证。** 每次启动要求实际隔离资源、同通道前检和进程树身份核对；缺失或不明时返回 `NETWORK_PROTECTION_UNAVAILABLE`。外部全路径及故障验收仍待补齐，不用直连替代代理需求。
2. **备份与诊断不是同一种文件。** `.prismbackup` 是包含浏览数据的完整备份；诊断 `.json` 只用于排错，不能恢复环境；网页演示 JSON 也不能导入真实工作区。
3. **当前新增流程请用合成测试数据。** 全量回归、真实桌面和新安装包验收尚未执行；跨电脑、重装系统后的网站登录保持没有承诺。

## 1 安装、升级与数据位置

Windows 10/11 x64 需要 WebView2；它只承载工作台页面，实际浏览环境使用 fingerprint-chromium。安装前核对该构建旁的 `release.json` 和 `SHA256SUMS`，签名以实际检查记录为准。旧预览未签名；源码中的版本字符串不能证明新包已构建或签名。

工作区默认位于 `%LOCALAPPDATA%/PrismBrowser/`，配置为 `app.db`，浏览数据各自独立。正常关闭后升级；卸载默认保留工作区。只有明确选择并再次确认删除全部数据才永久删除。详细步骤见[安装说明](INSTALLATION.md)。

## 2 第一次创建环境

1. 打开“内核管理”，安装指定 fingerprint-chromium 精确构建。使用官方固定版本及预期 SHA-256，或从文件选择器选择明确可信的本地 ZIP。安装失败先处理原因。
2. 打开“环境管理”新建，填写名称，选定内核与网络策略，调整语言、时区和窗口偏好。
3. 生成并查看设备档案，确认后保存。保存前的预览可取消；保存后 seed 固定。普通编辑、关闭、重开或换代理都不会自动换身份。
4. “重新生成”是明确改变草稿身份；需要保存才生效。档案历史回滚也要预览并明确提交。

CPU、GPU、字体等支持范围以该精确构建能力记录为准。窗口尺寸只是偏好，不等于伪造屏幕指纹。不同 seed 不保证每个输出都不同。

## 3 网络、打开与关闭

代理页支持 HTTP、HTTPS 上游与 SOCKS5 配置、认证和独立检查。凭据使用当前 Windows 用户的本机保护存储。HTTPS 上游指连接代理本身使用 TLS；HTTP/SOCKS5 认证本身不加密。

绑定代理环境启动时创建独立容器与专属桥，检查失败会拒绝启动；当前仅本机受控链路验证通过。启动、停止有独立任务状态；出现“结果待核实”时核对原任务，不把它当成失败后立即重建。资源清理不明时环境继续占用，保留原数据和日志。

优先正常关闭。超时、控制通道断开或应用重开后身份未知时，按提示核对准确会话；只有页面明确提供时才强制结束该受控会话。不要凭 PID 或锁文件年龄手工删锁。环境未确认完全退出前不进行目录替换。

## 4 Cookie 与批量操作

Cookie 导入选择明确环境和会话，先粘贴 JSON/Netscape 内容预览，再选定条目。合并与“替换全部”含义不同：后者会先清空该会话的 Cookie，需要明确选择。看实际读回核对数量；未知、失败或过期不能算成功。Cookie 内容不进入诊断。

批量新建、配置复制和代理分配会冻结所选目标，逐项记录结果。复制配置会生成新身份和空浏览数据，不复制登录状态。取消保留已完成项，重试沿用对应任务记录。**T14 真实启动队列仍待实现/集成**，不把演示批量启动当成桌面能力。调度并发用于资源保护，不是保存或保持运行数量配额。

## 5 完整备份与恢复

1. 在“备份恢复”选择全部环境或明确选定的环境，选择工作区以外的新 `.prismbackup` 文件。
2. 确认允许正常关闭范围内会话后导出。无法确认停止时中止，不自动强杀。
3. 等到“完整备份已发布”，保留文件和 SHA-256。临时 `.partial` 不是完成包。包包含网站数据，请妥善保管；诊断不需要附上备份。
4. 恢复时从系统选择器选备份，先只读预检，查看新增、覆盖、冲突、缺失内核及需重输凭据的条目。
5. 缺失精确内核时先补齐；确认覆盖和凭据处理，再执行恢复。备份不包含内核二进制。恢复保留原身份，撤回备份后的对应数据改动。
6. 中断或结果未知时使用原恢复任务核对/恢复入口。工作区维护屏障解除前不要手工换目录；硬中断恢复的源码存在，但真实故障验证仍待执行。

代理密文只面向原 Windows 用户；不承诺跨用户、跨机器可解密。仅备份一个环境也可能涉及共享代理引用，预检结果为准。

## 6 回收区与内核升级

移除环境先进入回收区，原身份和数据引用保留。找回恢复原环境；永久删除需要明确确认，部分删除失败按原任务收敛，不能视为可完整找回。

内核页的默认构建只影响后续新草稿。已有环境升级需明确选择一个已停止环境：查看差异 → 完整备份 → 在工作副本上先旧后新试用 → 正常停止副本 → 明确切换。失败或取消保留原状态。旧内核不能直接打开已升级目录；需要退回时使用迁移记录中的升级前完整备份。代理副本使用正式隔离和前检；合成存储试用通过私有管道供页，只验证该受控条件，不代表所有网站兼容或外部出口验收。

## 7 出问题时导出脱敏诊断

1. 在“活动记录”点击“生成诊断预览”。若数据库无法打开，可直接在“工作区需要处理”对话框中生成最小报告。
2. 查看字段，然后点击“保存这份诊断 JSON”，选择工作区外的新文件。服务不覆盖已有文件；取消保存不会写出文件。
3. 保存回执 SHA-256 与预览一致才显示已保存。连接中断时点“核实原导出”；离开页面后返回仍保留原请求。
4. 若原文件被移动或存储盘不可读，核实可能无法结束。可以明确“结束此次核实”，保留旧文件可能已发布的事实，再生成新报告。应用会话内保留旧请求回执；应用重启后不自动重放任何导出，请自行核对原位置。

报告白名单仅含版本、构建摘要、已保存状态、错误码、计数与维护标志，不包含名字、备注、路径、主机名、代理地址、IP、凭据、Cookie、浏览数据、ID、seed、命令行或原始日志。最多列出最近 100 条任务、100 条会话和 20 个内核；工作区繁忙/损坏可返回最小或部分报告。它不会启动内核、检测网络、刷新未落盘状态或上传文件。签名字段为“本次未检查”，实际签名查看对应构建的发布记录。

常见处理：

| 提示 | 下一步 |
| --- | --- |
| `NETWORK_PROTECTION_UNAVAILABLE` | 本次会话隔离核对未通过；查看诊断，保留原环境，不改直连绕过 |
| `KERNEL_MISSING` / `KERNEL_INTEGRITY_FAILED` | 核对并安装所需精确构建，不随意换版本 |
| `PROCESS_STOP_TIMEOUT` / `SESSION_IDENTITY_UNCONFIRMED` | 先核对原会话；目录保护期间不手工替换 |
| `STORAGE_WRITE_FAILED` / `DISK_FULL` | 检查空间、权限；核实原操作，保留原数据 |
| `*_RESULT_UNCONFIRMED` | 核实原请求/任务，不按“未执行”另建破坏性操作 |
